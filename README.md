# yield-curve

Восстановление кривой бескупонных ставок по ОФЗ-ПД (Мосбиржа, 2024-01 — 2026-10) и сравнение методов,
в том числе в стрессовых рыночных режимах.

Методы: бутстрэп (2 варианта), Нельсон–Сигель, Свенссон, NS с фиксированным τ, NS с якорем на RUONIA,
сглаживающий сплайн форвардов (VRP); эталон — КБД Мосбиржи.

Проверки: ошибка в выборке и вне её (leave-one-out на каждом дне, с доверительными интервалами),
длинный конец, нехватка выпусков (случайная и сценарии «как в стресс»), шум цен в пределах спреда,
модельный риск в рублях, дни заседаний ЦБ, главные компоненты, форварды как прогноз (тест Диболда–Мариано).
Рыночные режимы (спокойно / обычно / стресс) — по волатильности 10-летней ставки КБД и просадке RGBI.

«Точный взгляд» на ключевые дни: прогноз решения ЦБ к каждому заседанию, кривые каждые 30 минут
(10-минутные свечи) в дни заседаний, 30 самых стрессовых и 30 спокойных дней, настоящий спред бид/аск
(котировки на закрытие из файлов КБД).

## Запуск

```
pip install numpy pandas scipy matplotlib reportlab
python download_data.py            # ~25 мин; если https до биржи не проходит: ISS_BASE=http://iss.moex.com/iss/ python download_data.py
python run_analysis.py --tune      # (по желанию) подбор τ и штрафа сплайна
python run_analysis.py             # ~50 мин на 6 ядрах -> results/*.csv
python report.py                   # results/summary.md, results/numbers.json, results/fig_*.png
python events.py                   # заседания ЦБ и настоящий спред -> results/events.json
python download_intraday.py        # ~25 мин; 10-минутные свечи по выбранным дням (тоже через ISS_BASE)
python intraday.py                 # ~1 мин; внутридневные кривые -> results/intraday.json
python docs/build_explainer.py     # docs/Объяснение_проекта.pdf
python docs/build_report.py        # docs/Предварительный_отчет.pdf (для преподавателя)
python docs/build_report_short.py  # docs/Предварительный_отчет_кратко.pdf
```

Итоговые таблицы — `results/summary.md`, объяснение «с нуля» — `docs/Объяснение_проекта.pdf`.
